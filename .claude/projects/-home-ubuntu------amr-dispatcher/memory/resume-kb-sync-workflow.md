用户维护简历知识库文件 `机器人项目简历知识库.md`（位于 amr_dispatcher 仓库根目录）。用户提供新版简历文本后，要求把知识库同步修改为与简历一致：正文五条要点用简历原文，`核对备注（供面试问答参考）` 保留/新增逐条支撑（精确到文件与行号，数字须为仓库实测值）。

**Why:** 知识库是面试问答的底稿，正文与简历不一致会被追问时露馅；核对备注必须基于源码事实而非臆测。

**How to apply:** 简历更新 → 先 grep/read 仓库验证新声明（如 rclcpp_lifecycle、幂等、mtime 热重载）→ 重写正文对齐简历原文 → 扩充核对备注（含已知局限，主动标注"别说错"的点）。同名模式在其他项目也有（如 `AI-powered-Network-Diagnostics/弱网项目简历知识库.md`）。本次对齐日期：2026-10-09。

**知识库结构规范（2026-10-10 起）：** 机器人项目知识库已按 `弱网项目简历知识库.md` 的格式重构，固定骨架为：简历主文（引用块）→ 每条目含〔简历标准写法、可验证断言拆解表（断言/落点/关键代码）、背景知识 A/B/C…、代码走读核心片段（带文件行号）、面试问答汇总、30 秒应答模板〕→ 附录（Elevator Pitch、量化大表、STAR 排障故事两大深水区）。后续同步必须沿用此结构，不得回退成扁平的核对备注列表。
