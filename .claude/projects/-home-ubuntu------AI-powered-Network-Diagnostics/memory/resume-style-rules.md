用户对中文技术简历的四条硬性写作要求，已落地到 skills/writing-resume：

1. 不要括号、箭头、斜杠。斜杠统一用顿号 `、`。
2. 每点不超过黑体五号字两行（约 60 至 80 中文字符）。
3. 禁止使用项目内部术语（内部类名、命令名、配置项、变量名），必须用行业公认技术名词。
4. 简洁严谨，不写技术点的具体实现细节，不堆砌自我吹嘘式形容词。

**Why**：用户主动提出这四条，并要求沉淀为可复用的写简历 skill，说明这是他在多个场景下都要遵守的偏好，不是单次修订。

**How to apply**：所有中文技术简历润色、改写、新写场景，默认应用以上四条。英文专有名词内部固有的 `/` 与 `()` 保留。例外必须用户明确同意。
