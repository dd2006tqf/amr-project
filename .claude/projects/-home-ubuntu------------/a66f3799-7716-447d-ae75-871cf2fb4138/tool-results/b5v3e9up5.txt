## 0. 文档定位

本文是 5 月版 V1.2.0 主文档的**模块协作伴生文档**。主文档以"任务（T1~T5）"为主线讲接口与时序，本文以"模块视角"讲职责分配与协作拓扑，便于：

1. **GUI / 媒体 / 蓝牙 / 应用 4 个团队**各自快速摸到自己负责的工作清单
2. **PM / 评审人**理解模块依赖与并发可行性
3. **联调 / QA**根据协作拓扑设计跨模块测试用例
4. **5 项新需求**（含交互稿）逐项落地到主文档外的细化设计中

### 2.8 关键产品约束（贯穿全文）

- **AI 分析中不可退出**：用户必须等到分析完成才能离开
- **请勿拔卡**：修图过程中提醒不要操作 SD 卡
- **多张并发上限**：未明确数值（建议 ≤ 5 张排队，本文 §3.4 应用层默认）
- **不上云、不被 MTA 互传发现**：相册标志位由媒体/存储模块处理（与 4 月一致）
- **AI 修图标识 icon**：与 APP 端保持统一（icon 待 APP 端确认）

## 7. 蓝牙性能 KPI 专项（需求 N1）

### 7.1 KPI 总目标（产品输入）

| 指标                  | 目标             | 测量条件                                            |
| --------------------- | ---------------- | --------------------------------------------------- |
| **总连接耗时**        | ≤ 4 s（A1 → A5） | 已配对场景；正常电量；2 m 距离；无干扰              |
| **连接稳定性**        | ≥ 99% 成功率     | 100 次连续连接断开循环；含已配对 + 全新配对 50 + 50 |
| **吞吐 — iOS**        | 稳态 ≥ 50 KB/s   | BLE 路径；连续传 ≥ 100 KB                           |
| **吞吐 — 安卓**       | 稳态 ≥ 100 KB/s  | SPP 路径；连续传 ≥ 100 KB                           |
| **单文件传输 — iOS**  | ≤ 1 s            | 256×256 HEIF（约 12 KB）                            |
| **单文件传输 — 安卓** | ≤ 500 ms         | 256×256 HEIF（约 12 KB）                            |

### 7.2 子目标分解

| 子项                       | iOS         | 安卓       | 实现要点                               |
| -------------------------- | ----------- | ---------- | -------------------------------------- |
| BLE 建链耗时               | ≤ 1.5 s     | ≤ 1.5 s    | iBeacon 优化 + 协商参数预设            |
| 经典蓝牙开启耗时           | —           | ≤ 0.5 s    | 蓝牙栈预热                             |
| SPP 反向连接耗时（CL-1 E） | —           | ≤ 1.5 s    | RFCOMM 通道复用                        |
| 总建链                     | ≤ 1.5 s     | ≤ 3.5 s    | 上述累加（含 0.5 s 系统开销）          |
| BLE 连接间隔               | 7.5 ~ 15 ms | —          | 主从协商 (Connection Parameter Update) |
| BLE MTU                    | 247 字节    | —          | MTU 协商                               |
| SPP MTU 与流控             | —           | 默认或调优 | 测试驱动                               |
